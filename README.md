# XJTUCS Course PPT

本仓库是 [XJTUCS Guide](https://github.com/XJTUCS-HUB/XJTUCS-Guide) 的课程 PPT 附属仓库，用于按课程集中存放已获授权公开的课件。

本项目不代表学校、学院或课程团队。

## 目录结构

```text
courses/
└── {小写课程代码}/
    ├── README.md    # 课程名称、代码及目录说明
    └── slides/      # 该课程的 PPT、PPTX 或 PDF 课件
```

不同教师、学期或版本的课件较多时，可以继续在 `slides/` 下按 `学年学期-教师或版本` 建立子目录，例如：

```text
courses/comp400505/slides/2025-秋-某教师/
```
